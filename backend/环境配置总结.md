# 环境配置总结

## 📁 项目结构

```
backend/
├── src/main/resources/
│   ├── application.yml              # 主配置文件（包含dev/test/prod三环境）
│   └── README-环境配置.md           # 环境配置详细说明
├── .env.example                     # 生产环境变量模板
├── docker-compose.yml               # Docker容器编排
├── Dockerfile                       # 容器镜像构建
├── deploy.sh                        # 自动化部署脚本
└── 环境配置总结.md                  # 本文件
```

## 🚀 快速开始

### 1. 开发环境
```bash
# 方式一：直接运行（默认dev环境）
mvn spring-boot:run

# 方式二：使用部署脚本
./deploy.sh dev

# 方式三：指定profile
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

### 2. 测试环境
```bash
# 使用Docker Compose
./deploy.sh test

# 或手动启动
docker-compose --profile test up -d
```

### 3. 生产环境
```bash
# 1. 配置环境变量
cp .env.example .env
vim .env  # 编辑配置

# 2. 部署
./deploy.sh prod
```

## 🔧 配置文件说明

### application.yml
- **通用配置**：应用名称、服务器端口、JWT基础配置等
- **dev环境**：H2数据库、详细日志、宽松安全策略
- **test环境**：H2持久化、简化日志、中等安全策略
- **prod环境**：MySQL数据库、文件日志、严格安全策略

### .env.example
生产环境环境变量模板，包含：
- 数据库连接配置
- Redis连接配置
- JWT安全密钥
- 会话管理配置

### docker-compose.yml
容器编排配置，支持：
- 完整的生产环境（app + mysql + redis）
- 开发环境（app + redis，使用H2）
- 测试环境（独立端口8081）

### Dockerfile
多阶段构建：
- 构建阶段：Maven编译打包
- 运行阶段：轻量级JRE镜像
- 安全特性：非root用户运行
- 健康检查：自动监控应用状态

### deploy.sh
自动化部署脚本功能：
- 环境验证和依赖检查
- 自动构建和测试
- 不同环境的部署策略
- 健康检查和错误处理

## 🌍 环境特性对比

| 特性 | 开发环境(dev) | 测试环境(test) | 生产环境(prod) |
|------|---------------|----------------|----------------|
| 数据库 | H2内存 | H2持久化 | MySQL |
| 日志级别 | DEBUG | WARN | WARN |
| JWT过期 | 24小时 | 1小时 | 1小时 |
| 并发会话 | 3个 | 2个 | 1个 |
| 会话策略 | 踢出旧会话 | 拒绝新登录 | 拒绝新登录 |
| Redis数据库 | 0 | 1 | 0 |
| 端口 | 8080 | 8081 | 8080 |
| 容器化 | 可选 | 推荐 | 必须 |

## 🚨 故障排除

### 常见问题

1. **应用启动失败**
   ```bash
   # 检查Java版本
   java -version
   
   # 检查端口占用
   netstat -tulpn | grep 8080
   
   # 查看详细日志
   mvn spring-boot:run -X
   ```

2. **数据库连接失败**
   ```bash
   # 检查MySQL服务
   systemctl status mysql
   
   # 测试连接
   mysql -h localhost -u root -p
   
   # 检查防火墙
   sudo ufw status
   ```

3. **Redis连接失败**
   ```bash
   # 检查Redis服务
   redis-cli ping
   
   # 查看Redis日志
   sudo journalctl -u redis
   ```

4. **Docker部署问题**
   ```bash
   # 查看容器状态
   docker-compose ps
   
   # 查看容器日志
   docker-compose logs app
   
   # 重新构建镜像
   docker-compose build --no-cache
   ```
